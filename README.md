📍 TamoAqui

«Uma plataforma para aproximar cidadãos e o poder público.»

🌐 Acesse o projeto: https://tamo-aqui.pages.dev

---

💡 Sobre o projeto

O TamoAqui é uma plataforma web criada com o objetivo de facilitar a comunicação entre cidadãos e órgãos públicos, tornando mais simples registrar problemas, acompanhar solicitações e dar visibilidade às necessidades da comunidade.

A ideia surgiu a partir de uma pergunta simples:

«"E se fosse mais fácil para a população mostrar o que precisa ser resolvido?"»

O projeto busca transformar reclamações e problemas do dia a dia em informações organizadas que possam chegar até quem pode solucioná-los.

---

🚀 O que o TamoAqui busca resolver?

Muitas vezes, problemas como:

- 🕳️ Buracos nas ruas
- 💡 Iluminação pública com defeito
- 🗑️ Problemas relacionados à limpeza urbana
- 🌳 Áreas públicas necessitando de manutenção
- 🚧 Problemas de infraestrutura
- 📢 Outras demandas da comunidade

acabam sendo difíceis de registrar, acompanhar ou encontrar informações sobre o andamento da solicitação.

O TamoAqui busca centralizar esse processo em uma experiência simples e acessível.

---

✨ Principais funcionalidades

👤 Para cidadãos

- 📋 Registro de ocorrências e solicitações
- 📍 Identificação do local do problema
- 📝 Descrição da situação
- 📸 Possibilidade de utilizar informações visuais
- 🔎 Acompanhamento das solicitações
- 📊 Visualização das demandas da comunidade

🏛️ Para órgãos públicos

A plataforma também possui uma proposta voltada para a administração pública, permitindo organizar e acompanhar as demandas recebidas da população.

A ideia é possibilitar:

- 📥 Recebimento de solicitações
- 📊 Organização das ocorrências
- 🔄 Atualização do status das solicitações
- 📈 Visualização das demandas
- 🗺️ Identificação de regiões com maior concentração de problemas

---

🛠️ Tecnologias

O projeto utiliza tecnologias modernas para desenvolvimento web, incluindo:

- TypeScript
- React
- Vite
- Supabase
- CSS
- Cloudflare Pages

A arquitetura do projeto está sendo desenvolvida pensando em escalabilidade, organização e facilidade de manutenção.

---

🗄️ Backend e banco de dados

O Supabase é utilizado como parte da infraestrutura do projeto, fornecendo recursos como:

- 🔐 Autenticação de usuários
- 🗃️ Banco de dados PostgreSQL
- 🔒 Row Level Security (RLS)
- ⚡ API
- ☁️ Infraestrutura em nuvem

A utilização de RLS permite controlar quais informações cada tipo de usuário pode acessar ou modificar.

---

👥 Perfis de usuário

O projeto possui uma estrutura pensada para diferentes tipos de usuários.

👤 Cidadão

Pode registrar e acompanhar ocorrências e participar ativamente da identificação de problemas da comunidade.

🏛️ Prefeitura

Pode receber, organizar e gerenciar as solicitações realizadas pelos cidadãos.

Essa separação permite que cada perfil tenha acesso às funcionalidades necessárias para sua função.

---

🎯 Objetivo do projeto

Mais do que criar apenas um site, o TamoAqui está sendo desenvolvido como uma proposta de tecnologia aplicada a problemas reais da sociedade.

O objetivo é criar uma ponte entre:

👥 Cidadãos → 📍 Problemas → 🏛️ Poder público → ✅ Soluções

---

📱 Projeto em desenvolvimento

O TamoAqui ainda está em desenvolvimento.

A versão atual funciona como um MVP, permitindo testar a proposta, coletar feedback dos usuários e identificar quais funcionalidades realmente fazem diferença antes de expandir o sistema.

Novas funcionalidades podem ser adicionadas conforme os resultados dos testes e da validação do projeto.
